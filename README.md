# 💗 Daily Mood Tracker

A beginner-friendly Python app that lets you save your daily mood and a short journal note.

## ✨ Features

* 😊 Save today's mood.
* 📝 Write a daily note.
* 📖 View your mood history.
* 💾 Stores moods in a JSON file.

## 🛠️ Built With

* Python 3
* JSON
* datetime

## ▶️ How to Run

```bash
python main.py
```

## 📸 Example Output

```text
💗 DAILY MOOD TRACKER 💗

1. Add Today's Mood
2. View Mood History
3. Exit
```
